# Galeriden Tycoon Development Guidelines

## Invariant Rules
1. **Zero Unicode Emojis**: Always use `VectorIconWidget` or native Flutter icons. No emoji characters in strings or UI.
2. **Zero Parentheses**: Do not use `(...)` in UI strings, button text, dialog descriptions, or event choices. Use ` • ` or ` - ` for formatting.
3. **Strict Ownership Gating**: Random events targeting side businesses or facilities must check `b.isOwned == true` and `isFeatureUnlocked(route)`.
4. **Reactive Button States**: State actions must immediately disable spam buttons with reactive updates (`Consumer` / `ref.watch`).
5. **No Unprompted Git Push**: Never run `git push` without explicit user request.
6. **Widget Test Timer Hygiene**: When writing widget tests that mount `gameCoreProvider`, always invoke `container.read(gameProvider.notifier).stopPeriodicOrganicOfferTimer()` during setup or teardown to prevent pending timer test assertion failures.
7. **Isolate Serialization for Heavy Models**: State persistence serialization must use Flutter `compute()` isolate execution with safe web fallback.
8. **Simultaneous 7-Language Localization**: Every newly developed feature, string, dialog, badge, and notification MUST be simultaneously and completely localized in all 7 supported languages (`tr`, `en`, `de`, `pt`, `es`, `ru`, `ar`) within `lib/core/localization/translations/` and `app_localizations.dart`. Hardcoded text or single-language additions without full 7-language synchronization are strictly forbidden.
9. **AdMob Request Storm & Show Rate Hygiene**: Never place `loadRewardedAd()` in screen `initState()` or build methods. Rewarded ad preloading must strictly follow singleton lifecycle replenishment (load on startup, replenish on ad dismissed). Failed ad requests must enforce a minimum 45-second cooldown and gentle backoff (max 2 retries >= 30s). Native advanced ad widgets must strictly enforce at least a 1.5-second viewport dwell debounce to eliminate unviewed ghost requests from fast list scrolling.
10. **In-Universe Native Ad Lore Fallback & ListView Integrity**: When embedding `NeoBrutalNativeAdCard` within `ListView.builder` or slivers, composite index items MUST always be wrapped in a single parent container (such as `Column(crossAxisAlignment: CrossAxisAlignment.stretch)`). Every native ad context MUST define complete in-universe offline lore fallbacks (`InGameSponsorSnippet`) matching the screen domain. All ad-related CTAs must strictly use soft psychological framing (e.g. "Sponsor Desteği Al" instead of "Reklam İzle").
11. **Neo-Brutalist Visual Grammar & Tactical Design Invariants**: All UI components, cards, banners, dialogs, and interactive buttons must strictly follow neo-brutalist tactile geometry: 2.0px to 3.0px solid borders (pure black or deep slate in dark mode), hard 0-blur offset shadows (`blurRadius: 0`, offset 3.0px to 5.0px), flat high-saturation fills (brutalYellow, toxicLime, brutalCyan, brutalGreen, brutalOrange) without diffuse gradients, mechanical downward-press compression (`Transform.translate`), and angled sticker badges or rubber stamps. Never use soft material drop-shadows or subtle low-contrast pastel outlines.
